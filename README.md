# Martínez Multimarca — web

Prototipo de la nueva web de Martínez Multimarca (Verín, Ourense). Página única en HTML/CSS/JS sin dependencias de build, pensada para GitHub Pages.

## Contenido
- Venta de vehículos de ocasión (garantía 1 año, IVA incluido).
- Reprogramación y preparación de competición.
- Alquiler de vehículos y camper.
- Galería con entregas reales recientes (fotos tomadas de [@martinez_multimarca](https://www.instagram.com/martinez_multimarca/)).
- Contacto: Avda. de Castilla 163, Verín · 607 91 73 39 · simon@martinezmultimarca.com.

## Ver en local
Abre `index.html` en el navegador — no requiere servidor ni instalación.

## Publicar con GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `/ (root)`. La web quedará disponible en `https://<usuario>.github.io/<repo>/`.
